# Kirana Order Hub

A B2B FMCG ordering platform for distributors and retailers, featuring AI-powered order capture, a custom Scheme Engine, and an Order Desk dashboard.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL (via Prisma ORM)
- **Authentication:** NextAuth.js (Role-based)
- **AI:** OpenAI (with deterministic fallback)
